# OSISA Website

## Open Society Initiative for Southern Africa

This project is a multi-page website created to provide information about the Open Society Initiative for Southern Africa (OSISA), its focus areas, programmes, resources and contact information.

The website was developed as part of a web development project using HTML5 and CSS3.

---

## Project Objectives

The main objectives of this website are to:

- Create a clear and user-friendly website.
- Provide information about OSISA and its work.
- Present key focus areas such as democracy and human rights.
- Provide information about programmes and resources.
- Provide an enquiry form for visitors.
- Provide contact information.
- Create a responsive website that works on different screen sizes.

---

## Website Pages

The website contains the following pages:

1. **Home** – Introduces OSISA and highlights its main focus areas.
2. **About Us** – Provides information about OSISA and its mission.
3. **Programmes** – Presents the main programme areas.
4. **Resources** – Provides information about available resources.
5. **Enquiry** – Contains a form that visitors can use to submit an enquiry.
6. **Contact** – Provides contact information and a link to the enquiry page.
